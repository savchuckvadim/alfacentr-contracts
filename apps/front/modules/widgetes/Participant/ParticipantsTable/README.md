# ParticipantTableRowItem - Рефакторинг

Компонент таблицы участников был разбит на более мелкие, переиспользуемые компоненты для улучшения читаемости, тестируемости и поддерживаемости кода.

## Структура после рефакторинга

```
components/
├── ParticipantTableRowItem.tsx     # Основной компонент строки
├── cells/                          # Компоненты ячеек
│   ├── index.ts                    # Экспорт всех ячеек
│   ├── IndexCell.tsx               # Ячейка с номером
│   ├── NameCell.tsx                # Ячейка с именем и ID
│   ├── ContactCell.tsx             # Ячейка с email/телефоном
│   ├── FormatCell.tsx              # Ячейка с форматом обучения
│   ├── ProgramsCell.tsx            # Ячейка с программами ППК
│   ├── ProductsCell.tsx            # Ячейка с товарами
│   ├── PpkStatusCell.tsx           # Ячейка со статусом ППК
│   └── ActionsCell.tsx             # Ячейка с действиями
├── hooks/
│   └── useParticipantRowData.ts    # Хук для получения данных
└── utils/
    └── tooltipUtils.tsx            # Утилиты для tooltip'ов
```

## Компоненты ячеек

### IndexCell

- **Назначение**: Отображает порядковый номер участника
- **Props**: `index: number`
- **Особенности**: Стилизован как primary цвет

### NameCell

- **Назначение**: Отображает имя участника и его ID
- **Props**: `participant: IParticipant`, `name: string`
- **Особенности**: Ссылка на детальную страницу, hover эффекты

### ContactCell

- **Назначение**: Отображает email или телефон
- **Props**: `value: string`, `type: 'email' | 'phone'`
- **Особенности**:
    - Автоматические ссылки (mailto:, tel:)
    - Иконки (Mail, Phone)
    - Обработка пустых значений

### FormatCell

- **Назначение**: Отображает формат обучения
- **Props**: `format: string`
- **Особенности**:
    - Цветовая кодировка (Онлайн/Очно/Другое)
    - Badge компоненты

### ProgramsCell

- **Назначение**: Отображает количество тем ППК
- **Props**: `programs: string`, `participantPpkTopicsStats: any[]`
- **Особенности**:
    - Tooltip с списком тем
    - Badge с количеством

### ProductsCell

- **Назначение**: Отображает товары и проблемы
- **Props**: `assignedProducts: any[]`, `participantPpkTopicsStats: any[]`
- **Особенности**:
    - Tooltip с детальной информацией о товарах
    - Отдельный badge для проблем
    - Обработка отсутствия товаров

### PpkStatusCell

- **Назначение**: Отображает статус ППК
- **Props**: `isPpk: boolean`
- **Особенности**:
    - Зеленый badge для "Да"
    - Outline badge для "Нет"

### ActionsCell

- **Назначение**: Отображает кнопки действий
- **Props**: `participant: IParticipant`, `onEdit: function`, `onDelete: function`
- **Особенности**:
    - Кнопка просмотра (Eye)
    - Кнопка редактирования (Edit)
    - Кнопка удаления (Trash2)
    - Tooltip'ы для каждой кнопки

## Хуки

### useParticipantRowData

- **Назначение**: Объединяет данные из разных источников
- **Возвращает**: Все необходимые данные для строки таблицы
- **Преимущества**:
    - Централизованное получение данных
    - Легко тестировать
    - Переиспользуемость

## Утилиты

### tooltipUtils

- **Назначение**: Создание tooltip'ов для различных данных
- **Функции**:
    - `createProgramsTooltip` - для программ ППК
    - `createAssignedProductsTooltip` - для назначенных товаров
    - `createMissingProductsTooltip` - для проблем с товарами

## Преимущества рефакторинга

### ✅ **Читаемость**

- Каждый компонент отвечает за одну задачу
- Понятные названия и структура
- Меньше вложенности

### ✅ **Переиспользуемость**

- Ячейки можно использовать в других таблицах
- Хуки можно переиспользовать
- Утилиты универсальны

### ✅ **Тестируемость**

- Каждый компонент можно тестировать отдельно
- Легко мокать зависимости
- Изолированная логика

### ✅ **Поддерживаемость**

- Изменения в одной ячейке не влияют на другие
- Легко добавлять новые ячейки
- Простое изменение логики

### ✅ **Производительность**

- Компоненты перерендериваются только при изменении своих props
- Меньше ненужных вычислений
- Оптимизированные re-renders

## Пример использования

```tsx
import { ParticipantTableRowItem } from './components/ParticipantTableRowItem';

// В родительском компоненте
<ParticipantTableRowItem
    participant={participant}
    index={index}
    handleDeleteClick={handleDelete}
/>;
```

## Добавление новой ячейки

1. Создать компонент в папке `cells/`
2. Добавить экспорт в `cells/index.ts`
3. Импортировать и использовать в `ParticipantTableRowItem.tsx`
4. При необходимости добавить данные в `useParticipantRowData`
