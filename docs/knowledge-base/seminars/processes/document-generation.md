# Генерация документов

Документы формирует Битрикс по шаблонам, приложение готовит для них данные и собирает результат.

## Состав пакета

Договор, счёт, акт. Для договоров ППК и Семинар+ППК дополнительно «Приложение №1» — таблица, где строка = пара «участник × программа»: ФИО, телефон, email, программа обучения, дата начала, дата окончания.

## Как это происходит

1. Менеджер нажимает «Сделать документы».
2. Открывается окно подтверждения: обязательные поля — дата акта, банк, контактное лицо, email, телефон. У договоров ППК добавляется раздел с таблицей приложения.
3. **Отправка блокируется**, пока у каждого участника не заполнено ФИО и у каждой пары не заполнены обе даты, причём начало не позже окончания.
4. Правки из окна применяются к участникам, затем формируются документы.
5. Приложение ждёт, пока Битрикс отдаст готовые PDF, и складывает файлы в поля сделки.

## Где смотреть, если что-то не сошлось

**«Документы не готовы».** Битрикс не успел сформировать PDF за отведённое время. Повторите через минуту — данные не потеряны.

**В приложении пустые даты.** У участника не заполнены даты по программе. Их можно заполнить заранее в табе «Приложение ППК», не открывая окно отправки.

**Шапка приложения обещает больше, чем в нём есть.** Шапка приведена к фактическому составу: ФИО, телефон, email, программа обучения.
