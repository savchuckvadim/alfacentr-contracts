## Поля сделки

Настройки CRM → Настройки форм и отчётов → Пользовательские поля → Сделка. Искать по техническому коду.

| Поле | Код | Значения и смысл |
|---|---|---|
| Префикс | `UF_CRM_8_PREFIX` | префикс договора, из названия товара |
| Номер текущего договора | `UF_CRM_8_NUMBER_CURRENT_DOC` | порядковый номер внутри префикса |
| Номер документа | `UF_CRM_8_NUMBER_DOC` | номер документа, не номер договора — не путать |
| Тип заявки (скрытое) | `UF_CRM_1771410918` | Семинары, Учетная политика |
| Тип организации | `UF_CRM_1744358047` | Физическое лицо, Юридическое лицо |

## Поля смарт-процесса «Семинары» (159)

| Поле | Код | Смысл |
|---|---|---|
| Префикс | `UF_CRM_8_PREFIX` | префикс договора |
| Номер текущего договора | `UF_CRM_8_NUMBER_CURRENT_DOC` | номер договора |
| LIST_ID | `UF_CRM_8_LIST_ID` | ID элемента-счётчика, по которому карточка нашла номер |
| Сделка | `parentId2` | связь со сделкой |

Стадии воронки 16: `NEW` «Выбор товара», `PREPARATION` «Создать документы», `UC_W8YHZ2` «Отправить клиенту», `SUCCESS` «Завершить», `FAIL` «Отказ».

## Поля товара

Карточка товара в каталоге → свойства.

| Поле | Код | Смысл |
|---|---|---|
| Название в заявке | `property402` | единственная связь текста из формы с товаром |

Префикс и тип товара отдельными полями не хранятся — читаются из названия товара после маркера `[]`.

## Ставки НДС

Настройки торгового каталога → Ставки НДС.

| Ставка | ID |
|---|---|
| Без НДС | 2 |
| НДС 18% | 4 |
| НДС 5% | 6 |

Товарные позиции сделки создаются с НДС 5%, включённым в цену. У товаров каталога ставка не заполнена, поэтому задаётся на позиции.
