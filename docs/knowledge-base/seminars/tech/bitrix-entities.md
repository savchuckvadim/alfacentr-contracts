# Сущности Битрикса

| Сущность | ID | Для чего |
|---|---|---|
| Сделка, воронка «Семинары» | — | новая технология: заявка, товары, документы |
| Смарт-процесс «Семинары» | `159`, воронка `16` | старая технология, работает параллельно |
| Смарт-процесс «Участники» | `1036`, категория `26` | участник: ФИО, контакты, программы, даты обучения |
| Список «Договор» | `46` | счётчики номеров: один элемент = один префикс |
| Товарный каталог CRM | `24` | товары; префикс лежит в названии после `[]` |

## Список счётчиков 46

Три поля: название (сам префикс), «Активен» (`Да` = 156, `Нет` = 158), «Номер» (последний выданный).

Уникальность названия Битрикс **не проверяет** — два элемента с одинаковым названием возможны, и это главная историческая проблема нумерации.

## Поля смарта 159, которые важны

| Поле | Смысл |
|---|---|
| `UF_CRM_8_PREFIX` | префикс договора |
| `UF_CRM_8_NUMBER_CURRENT_DOC` | номер текущего договора |
| `UF_CRM_8_LIST_ID` | ID элемента-счётчика, по которому карточка нашла номер |
| `parentId2` | связь со сделкой |

Стадии воронки 16: `NEW` «Выбор товара», `PREPARATION` «Создать документы», `UC_W8YHZ2` «Отправить клиенту», `SUCCESS`, `FAIL`.

Те же по названию поля `UF_CRM_8_*` существуют и у сделки — новая технология пишет в них.

## Участники

Даты обучения лежат в служебном поле списком пар «программа — дата начала — дата окончания». Ключ связи — название программы, тот же текст, которым связаны распределение, товары и документ. Плюс служебное поле «Дата начала следующего мероприятия»: его пересчитывает регулярная задача, оно видно в карточке и работает в фильтрах.
